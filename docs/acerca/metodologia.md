# Cómo se hacen los resúmenes

## Fuentes

Cada resumen se construye a partir de, en este orden de prioridad:

1. **Guías clínicas internacionales vigentes** de las sociedades de referencia de cada subespecialidad (por ejemplo ESC, ACC/AHA, ADA, KDIGO, IDSA/ATS, ACG, ESGE, EASL, GOLD, GINA). Se usa la versión más reciente disponible; cuando una guía no tiene versión 2026 se indica el año de la última edición.
2. **Guías y documentos chilenos**: guías de práctica clínica GES del Ministerio de Salud (MINSAL), orientaciones técnicas, consensos de sociedades científicas chilenas y el perfil de conocimientos EUNACOM.
3. **Epidemiología**: Global Burden of Disease (IHME), OMS, Encuesta Nacional de Salud (ENS) y estadísticas del DEIS-MINSAL para Chile.
4. **Revisiones de revistas de alto impacto** (NEJM, Lancet, JAMA, BMJ, Nature Reviews Disease Primers) para fisiopatología y contexto.

Las referencias completas están al final de cada página.

## Imágenes

- **Esquemas y algoritmos propios**: diagramas dibujados para este sitio a partir de las guías citadas.
- **Figuras de artículos científicos**: solo de artículos de acceso abierto con licencia Creative Commons (CC BY o CC BY-NC), que permite reproducirlas citando la fuente. Cada figura indica autores, revista, año y licencia.
- **Figuras con derechos reservados** (por ejemplo, de NEJM, JAMA o Lancet): no se copian; se enlazan para verlas en la fuente original.

## Fecha de revisión

Cada página indica cuándo se revisó por última vez. Las guías cambian: si ves que salió una versión nueva de alguna guía citada, conviene actualizar la página.

## Limitaciones

Los resúmenes se redactan con apoyo de inteligencia artificial. Aunque cada dato relevante está referenciado, pueden existir errores u omisiones, sobre todo en dosis y puntos de corte. Este sitio es una herramienta de estudio personal y no reemplaza la guía original ni el juicio clínico.
